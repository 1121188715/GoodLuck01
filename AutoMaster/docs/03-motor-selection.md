# AutoMaster 电机选型与传动

## 1. 挥动轴

### 1.1 负载与运动

- **负载**：末端质量 = 柳条/木板 + 夹持器 + 阻尼关节 + 连接件，假设合计 **m ≈ 0.35 kg**，质心到转轴 **L ≈ 0.28 m**。
- **运动**：有效摆动角 **≥ 60°**（如 60°–90°），**最高频率 1 Hz**（周期 1 s）；最慢频率端优先选型简单或低成本方案（如 PWM 降速即可，无需额外减速档）。
- **惯性**：J ≈ m·L² ≈ 0.35×0.28² ≈ **0.027 kg·m²**。

### 1.2 末端力度要求与扭矩估算

- **力度要求**：最大值**略大于普通成年男性全力挥击**；最小值无硬性要求，具备一定可调区间即可。
- **估算**：成年男性持轻物（约 0.2–0.4 kg）全力挥击时，拍击瞬间末端线速度约 2.5–4 m/s，对应冲击力约 **40–80 N**（峰值，与接触时间、接触面积相关）。为“略大于”该效果，设计目标取：拍击瞬间末端线速度 **v ≥ 3–3.5 m/s**，即角速度 **ω = v/L ≈ 11–12.5 rad/s**。
- **运动学**：若半周期（挥下）t ≈ 0.35 s，从静止加速到 ω_peak ≈ 11 rad/s，近似匀加速则 **α ≈ 2×11/0.35 ≈ 63 rad/s²**。
- **扭矩**：T_accel = J·α ≈ 0.027×63 ≈ **1.7 N·m**；重力在臂水平时 T_grav = m·g·L ≈ 0.35×9.8×0.28 ≈ **0.96 N·m**。合计 **T ≥ 2.7 N·m**（输出轴），留 1.2–1.5 倍余量 → **挥动轴输出扭矩建议 ≥ 3.2–4 N·m**，对应电机侧按减速比折算。
- **转速**：60° 在 0.35 s 内完成 → 输出轴平均约 **30 rpm** 量级；电机若经 1:30–50 减速，则电机空载转速选 100–200 rpm 档即可，低速端通过 PWM 降速实现力度与频率调节。

### 1.3 选型方向（成本与可拓展性优先）

- **直流减速电机**：成本低，PWM + 方向即可调速度与力度；需 H 桥驱动。**推荐**：12 V 直流减速电机，**额定输出扭矩 ≥ 3.5 N·m**，额定转速 20–50 rpm 档（或更高转速配更大减速比），便于 1 Hz 满速与降速可调。
- **步进电机**：开环角度控制简单；需步进驱动器，高速时扭矩下降，需选保持扭矩足够且带减速的型号（或外接减速器）。
- **伺服电机**：性能最好，成本高；若后续需要高一致性与多档力度可拓展再考虑。

推荐电压 **12 V**（与整机统一）；接口为 **PWM + 方向**（直流）或 STEP/DIR（步进）。

## 2. 左右轴与远近轴

### 2.1 负载与运动（按成年男性背部覆盖）

- **负载**：整臂质量（含挥动机构与末端）约 **2–4 kg**，导轨/丝杠摩擦系数取 0.1–0.2 量级。
- **行程**（见 [02-mechanical.md](02-mechanical.md)）：**左右 ≥ 500 mm**，**远近 ≥ 400 mm**。
- **运动**：覆盖整背时按“每拍击一次移动一小步”或连续慢速扫描，平均速度 **10–25 mm/s** 即可；**最慢端优先简单/低成本**（步进开环 + 低细分或低脉冲频率即可）。

### 2.2 选型方向（成本与可拓展性优先）

- **步进电机**：结构简单、成本低，开环即可满足定位；**推荐** NEMA17 或等同 42 步进，保持扭矩 ≥ 0.3 N·m，配丝杠或同步带。左右/远近两轴可共用同一型号，便于采购与扩展。
- **直流电机 + 编码器**：可选，用于闭环与抗负载变化；若首版优先成本，可仅用步进开环。

传动与步距：

- **丝杠**：导程 2–4 mm；步进 200 步/圈、16 细分 → 3200 step/圈，每步线位移 ≈ 导程/3200（如 2 mm → 0.000625 mm/step），满足定位精度。
- **同步带**：带轮周长与步距角换算 mm/step；成本低、易扩展行程，需张紧与防打滑。

## 3. 力度调节

- **挥动轴**：力度由拍击瞬间角速度与末端质量决定。实现方式：
  - **PWM 占空比 / 目标速度**：降低挥动段 PWM 或目标角速度 → 拍击变轻；提高 → 变重。**最小值无要求**，仅需保证有一定可调区间（如 3–5 档）。
  - **电机电流/扭矩限制**（可选）：限制最大电流，避免过猛加速，与 PWM 配合实现档位。
- 固件与软件中建立“力度档位”（如 1–5）与 PWM/电流映射表即可。

---

## 4. 小结与文档

- **挥动轴**：输出扭矩 ≥ 3.2–4 N·m，支持 1 Hz 下 ≥60° 摆动；末端线速度可达 3–3.5 m/s 以实现“略大于成人全力挥击”；低速/轻力度端用 PWM 或降频即可，优先低成本。
- **左右/远近轴**：行程按成年男性背部 ≥500 mm / ≥400 mm；步进开环 + 丝杠或同步带，成本与可拓展性平衡。

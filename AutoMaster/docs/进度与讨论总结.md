## 今日完成内容（2025-03-15）

### 1. 基础设计文档与目录

- 建立 `AutoMaster/` 独立子项目，含 `docs/`、`hardware/mechanical/`、`hardware/electrical/`、`firmware/`、`software/` 等目录。
- 完成 5 篇设计文档：总览(01)、机械(02)、电机选型(03)、电气(04)、软件(05)。

### 2. 按你反馈做的设计收敛

- **设备位置**：相对人后背的位置由安装位置决定，不单独约束；**优先便携**，底座采用**吸盘立式机构**。
- **速度**：最高 1 Hz，最慢端优先**简单/低成本**（如 PWM 降速）。
- **行程**：按**成年男性**体型，左右 ≥500 mm、远近 ≥400 mm。
- **力度**：最大值**略大于普通成年男性全力挥击**，最小值无要求、有可调区间即可；已做估算（末端线速度 ≥3–3.5 m/s，挥动轴输出扭矩 ≥3.2–4 N·m）。
- **摆动角**：无硬性角度，**至少 60°**，能配合覆盖后背即可。

### 3. 硬件选型与 BOM 输出

- **机械**：`hardware/mechanical/dimensions.md`（关键尺寸）、`bom_mechanical.md`（整体机械 BOM）。
- **电气**：`hardware/electrical/bom_electrical.md`（ESP32、直流电机+H 桥、NEMA17+步进驱动、电源、限位等）。
- **挥动机构两套 BOM（可采购+估价）**：
  - **方案 A**：直流电机 + 直驱（摆臂、光轴、轴承等）→ CSV + HTML，预估约 **283 元**。
  - **方案 B**：曲柄摇杆/四杆（曲柄、连杆、摇杆、鱼眼接头等）→ CSV + HTML，预估约 **305 元**。
- 文件位置：`AutoMaster/hardware/mechanical/` 下  
  `BOM_挥动机构_方案A_直流直驱.csv`、`BOM_挥动机构_方案B_曲柄摇杆.csv`、`BOM_挥动机构_方案A与B_采购表.html`。

### 4. 设计优先级

- **成本**与**可拓展性**优先；具体型号见各 BOM，便于后续替换与扩展。

## 下次可继续的方向（建议）

1. **定稿挥动方案**：在方案 A 与 B 中选一，或先做一版原型再对比。
2. **采购与装配**：按选定方案的 BOM 采购，落地机械与电气，联调挥动轴。
3. **左右/远近轴**：若需要，可像挥动机构一样单独出一份带价格的 BOM（Excel/Word）。
4. **固件**：ESP32 工程、Wi-Fi/WebSocket、挥动轴 PWM 控制、限位与急停逻辑。
5. **控制端**：Web 控制页（力度、频率、范围、启停），与设备通信协议对接。

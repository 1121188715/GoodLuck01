# 机械相关文档

本目录用于存放 AutoMaster 机械部分的草图、尺寸说明与结构描述。

## 设计文档索引

- 机械方案总览、挥动与复位机构、左右/远近移动、末端平直拍打与夹持：见 [docs/02-mechanical.md](../../docs/02-mechanical.md)。
- 电机与传动选型（与机械负载、行程相关）：见 [docs/03-motor-selection.md](../../docs/03-motor-selection.md)。

## 本目录文件

- **[dimensions.md](dimensions.md)**：关键尺寸（行程、摆动角、臂长、底座等），按成年男性背部覆盖与便携优先。
- **[bom_mechanical.md](bom_mechanical.md)**：机械 BOM 与选型（挥动机构直流/四杆、左右远近传动、阻尼关节、夹持、吸盘底座等），成本与可拓展性优先。

### 挥动机构采购用 BOM（方案 A / 方案 B，含预估价格）

| 文件 | 说明 |
|------|------|
| **[BOM_挥动机构_方案A_直流直驱.csv](BOM_挥动机构_方案A_直流直驱.csv)** | 方案 A（直流电机+直驱）采购清单，可用 **Excel** 直接打开编辑，预估约 **283 元**。 |

## 文件命名与内容建议

- **草图**：可放置示意图或扫描件，建议命名如 `layout_sketch_v1.png`、`swing_mechanism_*.pdf`。
- 所有文件名建议带版本或日期后缀，便于迭代对比。
